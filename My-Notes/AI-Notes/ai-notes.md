# AI Notes

## Repository Memory

VS Code has a repository memory that persists even after shutting down the system. This memory is used by the AI to place notes, which allows the AI to follow the instructions of those notes.

### Key Behavior
- Sometimes the AI doesn't always follow the SKILL file for a specific instruction
- The repo memory would always guide the AI to use this Skill
- The AI has a function that it uses to get this memory
- You cannot see the memory as it is not in your local file
