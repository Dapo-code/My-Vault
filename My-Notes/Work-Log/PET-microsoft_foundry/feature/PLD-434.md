## Notes / Learnings
- `IndirectAttack` and `PersonallyIdentifiableInformation` are not valid `contentFilters` names in the stable `2024-10-01` Management API — they only exist in preview API versions or portal concepts
- Indirect attack (Prompt Shield for documents) is configured per-request via `prompt_shield.documents` in the chat completions API body, not in the RAI policy
- Model name must exactly match Azure's catalogue name — `gpt-5.6-lun` is not a valid model; the correct name is `gpt-5.6-luna`
- `members.tf` left empty — payments tribe must supply Entra object IDs before prod apply
