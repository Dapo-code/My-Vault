# Skill Index

This file is the canonical index of skills in this vault. It provides one place to discover all available skills, what each skill does, and where to open the corresponding folder-level skill note. Entries here should point to top-level skill note files and never directly to `SKILL.md` files.

## Vault Skills Index

- [[ObsidianSkills/index-update/index-update|Skill Index Update Skill]]
	Description: Maintains this skill index by adding, updating, and removing skill links with clear one-line descriptions.

- [[ObsidianSkills/daily-notes/daily-notes|Obsidian Daily Notes Skill]]
	Description: Creates or updates daily notes using required metadata, priorities, and a consistent daily structure.

- [[ObsidianSkills/changelog-maintenance/changelog-maintenance|Changelog Maintenance Skill]]
	Description: Adds concise dated changelog entries and routes skill-related updates to the skills changelog.

- [[ObsidianSkills/deduplication-cron/deduplication-cron|Duplicate Notes and Skills Cron Skill]]

- [[ObsidianSkills/skill-format-guide/skill-format-guide|Skill Format Guide]]
	Description: Defines the parameter-driven standard for creating new skill folders, SKILL.md files, and paired skill notes.

- [[ObsidianSkills/github-ssh-dapo-setup/github-ssh-dapo-setup|GitHub SSH Dapo Setup Skill]]
